# 无疆卡手机端报名

Vue 3 + Vite 的手机端展示页面，保留简介弹窗 → 登录 → 填表 / 已收到 → 修改信息的简洁流程。

```sh
npm install
npm run dev
npm test
npm run build
```

本地预览：`http://127.0.0.1:4173/`。构建产物为 `dist/`，使用相对资源路径，可部署到子目录。

## 报名体验

- 每次打开或刷新页面都显示紧凑介绍弹窗，说明卡片免费领取，下单支付 **9.9 元邮费**，流量另计，并明确 **无疆卡需先激活，才能发货**。提交前确认和已收到页面同步展示发货说明。完整卡面以缩略图展示，点击可在新窗口看大图。不展示预计数量或全员可报名文案。
- 移除独立的顶部品牌栏和“展示版”标记，表单顶部只保留报名标题、卡片介绍入口、身份信息与进度；页面底部保留前端演示说明。
- 登录后未提交者显示表单，已提交者显示“已收到，请等待”，支持修改和取消修改。
- 13 道题全部必填：使用城市、使用对象、领取张数、准备使用的设备、实际月流量、流量用途、当前上网方式、网络问题、希望解决的具体问题、使用时间、关注重点、真实经历、补充疑问。
- 领取张数不预选，提供 1 / 2 / 3 张快捷按钮，也可用数字键盘输入其他张数；必须为正整数，不设业务数量上限。提交后的摘要展示领取数量。
- 其他人、其他设备、其他选项、CPE 现有套餐和真实经历按选择展开并必填。“其他人”可快捷选择父母、伴侣等关系，也可自定义。
- 设备按系列展开，支持同系列及跨系列多选：C2000 系列（Ultra / Max / Plus / Pro+ / Pro / 其他）、AK-68 系列（AK-68 798 / AK-68 788 / 其他）、C8 系列（C8-788 / C8-688 / C8-668 / 其他），以及 NBCPE、其他。每个“其他”独立补充型号，切换或收起时保留草稿。选项仅用于收集设备信息，不表示已确认适配。
- 网络问题为“符合的都可选”，不限制为 2 项；“暂无明显问题”与其他问题互斥。关注重点仍最多选 2 项，点击第 3 项时提示先取消一项。短选项采用紧凑按钮，长选项整行可点。
- 月用量使用数字键盘，也可选择不清楚；现有套餐提供“不清楚”快捷填写。真实经历、补充疑问均可选择“暂时没有”，不必手动输入“暂无”。
- 后半部分的文字回答和补充说明不限制字数，输入、校验、保存均不截断，也不显示字数计数器；必填规则保留。长文本输入框随内容增高，示例默认收起，可按需展开查看，不会替用户填入答案。
- 真实经历、补充疑问在有内容和“暂时没有”之间切换时只收起输入框，不清空已输入文字；未提交的草稿恢复也保留这些文字。正式提交仍只记录最终选择，选择“暂时没有”时不会把收起的文字作为回答提交。
- 移除了匿名直播 / 短视频展示授权，不提供任何公开展示、上传或分享功能。
- 草稿自动保存，显示完成进度；提交时定位第一个未完成的问题。适配手机安全区和软键盘。

## 城市定位

`LocationCard.vue` 提供定位和手动选择两种路径，均只在表单中保存省份、城市，**不保存经纬度或精确地址**。

- 点击定位后才调用浏览器 Geolocation API。HTTPS / localhost 环境需用户允许定位。
- 当前位置仅用于调用 [BigDataCloud 浏览器城市解析接口](https://www.bigdatacloud.com/free-api/free-reverse-geocode-to-city-api)，不使用 IP 定位推断，不发送报名答案或账号信息。该服务无需 API key；失败或城市无法匹配时回退为手动选择。正式上线可按业务需要替换为自己的城市解析接口。
- 拒绝定位、超时、网络不可达或不支持定位均可手动选择；不强制授权。手动修改会取消待完成的定位，避免晚到的结果覆盖用户选择。
- 手动省市数据本地打包，来自 [Administrative-divisions-of-China](https://github.com/modood/Administrative-divisions-of-China)，许可证保存在 `src/data/LICENSE`。直辖市统一保存到市级；港澳及台湾、其他地区另作入口，不表示产品适用范围。
- 手动选择通过底部弹层提供中文城市 / 省份搜索，也可逐级选择省份和城市；未选择时关闭不会覆盖原城市。
- 定位结果处理和省市校验有单元测试；浏览器中验证了手动选择路径，真实设备定位效果依赖浏览器授权和服务可用性。

## 数据兼容

沿用存储键 `wujiang.signup.v1`。新版提交使用 `schemaVersion: 5`。前 4 版有效报名继续显示等待，领取数量显示“待补充”，不会擅自填为 1 张；修改时需补填数量并重新确认激活后发货说明。修改时迁移含义明确的答案；设备支持多选，兼容之前的单选答案；流量区间不会被擅自换成一个精确数值。原有关系和补充疑问文本会自动对应到新的选择方式，保留自定义内容。保留历史答案供编辑参考，新提交必须满足 13 题校验。

旧设备答案中的 Ultra 对应 C2000 Ultra，明确匹配的型号转为选项，未匹配型号保留在“其他”中；不把 C2000 Pro Max 等有歧义的旧名称猜成新选项。旧“暂未确定设备”保留为其他设备中的原意说明。

- `src/App.vue`：登录、提交状态和简介弹窗
- `src/components/RegistrationFields.vue`：题目和条件追问
- `src/components/DevicePicker.vue` / `src/devices.js`：分系列型号选择、独立补充和旧设备答案迁移
- `src/components/LocationCard.vue` / `CityPicker.vue` / `src/location.js`：城市定位、搜索、选择和解析
- `src/components/ChoiceGroup.vue` / `AutoTextarea.vue`：选项交互、限选反馈和自动增高文本输入
- `src/model.js`：新版校验、迁移和存储
- `src/previous-model-v3.js` / `src/legacy-model.js`：历史数据读取兼容
- `tests/`：必填、分支、互斥、定位数据、迁移和存储容错测试

## 后续接入

当前为前端展示版，有赞登录、Ultra 订单、灯牌等级为模拟数据，报名仅保存在当前浏览器，不分配名额、不生成订单、不付款。激活后发货目前为规则提示，实际激活核验和发货流程待后台接入。

`App.vue` 的 `signIn()` 和 `submit()` 分别是登录与报名接口接入位置；正式接入后由服务端核验身份、订单、灯牌、领取数量和报名状态。前端展示不能作为领取凭证。具体资费、共享范围、设备适配规则由正式后台提供。

介绍图为用户提供的黑金卡面 `public/images/wujiang-card-reference.png`。图片按原始比例完整显示。弹窗在 320×568 和 375×667 浏览器视口中无需滚动；极短视口或字体放大时正文可滚动，底部按钮保持可见。旧海报中的“待上线”和适用设备文字不作为当前产品规则。
