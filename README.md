# 无疆卡报名

Vue 3 + Vite 的手机端报名展示页，使用 Composition API 和单文件组件。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

本地地址：http://127.0.0.1:4173 。

```sh
npm test
npm run build
npm run preview
```

部署时执行 `npm ci && npm run build`，静态目录使用 `dist/`。Vite 已配置相对资源路径，可以部署到子目录。开发预览和构建预览使用同一端口，请先停止另一进程。

## 页面与交互

- 首次介绍弹窗 → 有赞演示登录 → 单页填写；已报名显示“已收到，请等待”，可修改或取消修改。
- 9 道核心题：使用对象、设备、实际月用量、网络困扰、联通体验、流量习惯、搭配方式、开始时间、真实使用场景。
- 家庭共享人数、设备型号、闲置 CPE 数量、其他网络问题和聚合准备情况按选择展开，隐藏时清除对应答案。
- 网络困扰和搭配方式最多选 2 项；无设备、暂无问题、不清楚等选项与同题其他答案互斥。
- 费用和直播疑问折叠为两道选填题；省市选填；不收家属姓名、手机号、设备码或截图。
- 大流量使用习惯会显示计费提醒；不根据任何选项承诺获得名额。
- 月用量使用底部面板，支持遮罩、关闭按钮、Esc 和浏览器返回关闭。
- 手机固定提交按钮，适配安全区和软键盘；错误定位到首个未完成问题，草稿自动保存。
- 沿用 `wujiang.signup.v1` 存储键。前两版已提交信息继续显示等待；编辑时保留旧答案供参考，仅迁移含义明确的答案，不替用户推断新增问题。提交新版表单后使用 schemaVersion 3。

## 文件

- `src/App.vue`：登录、提交状态和弹窗流程
- `src/components/RegistrationFields.vue`：报名题目与条件追问
- `src/components/QuestionField.vue`：问题标题、说明和校验提示
- `src/components/BottomSheet.vue`：底部弹窗、焦点管理与滚动锁定
- `src/components/ChoiceGroup.vue`：单选、多选、互斥和数量限制
- `src/model.js`：校验、数据清理、历史数据迁移与本地存储
- `src/legacy-model.js`：前两版记录的校验与读取兼容
- `tests/signup.test.js`：条件分支、选择限制、历史迁移和存储容错测试

## 后续接入

当前是前端演示：登录、Ultra 订单、灯牌信息是模拟数据，报名信息仅保存到当前浏览器，不分配资格、不生成订单、不付款。

`App.vue` 的 `signIn()` 是有赞登录接入位置，`submit()` 是报名接口接入位置。正式接入后由服务端核验身份、订单、灯牌和报名状态。展示数据不能作为领取凭证。

卡片免费领取，下单支付 9.9 元邮费，流量费用另计。首批预计 2,000 张；所有人可报名，Ultra 用户、灯牌等级优先参考。上线前需补充具体资费、共享范围和设备适配规则。

匿名场景展示授权独立选填，默认不勾选。当前没有公开展示、上传或分享功能。

框架参考：[Vue 快速开始](https://vuejs.org/guide/quick-start.html)、[表单输入绑定](https://vuejs.org/guide/essentials/forms.html)。
