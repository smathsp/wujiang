# 无疆卡手机端报名

Vue 3 + Vite 的手机端展示页面，保留简介弹窗 → 登录 → 填表 / 已收到 → 修改信息的简洁流程。

```sh
npm install
npm run dev
npm test
npm run build
```

本地预览：`http://127.0.0.1:4173/`。构建产物为 `dist/`，使用相对资源路径，可部署到子目录。

## 报名体验

- 每次打开或刷新页面都显示无疆卡介绍，明确本次每人免费领取 **1 张卡**，下单支付 **9.9 元邮费**，流量另计。不展示预计数量或全员可报名文案。
- 登录后未提交者显示表单，已提交者显示“已收到，请等待”，支持修改和取消修改。
- 12 道题全部必填：使用城市、使用对象、主要设备、实际月流量、流量用途、当前上网方式、网络问题、希望解决的具体问题、使用时间、关注重点、真实经历、补充疑问。
- 其他人、其他设备、其他选项、CPE 现有套餐和真实经历按选择展开并必填；切换选项时清除隐藏答案。
- 网络问题和关注重点最多选 2 项；“暂无明显问题”与其他网络问题互斥。月用量可填数字或选择不清楚；经历可选暂时没有，补充意见可写暂无。
- 移除了匿名直播 / 短视频展示授权，不提供任何公开展示、上传或分享功能。
- 草稿自动保存，显示完成进度；提交时定位第一个未完成的问题。适配手机安全区和软键盘。

## 城市定位

`LocationCard.vue` 提供定位和手动选择两种路径，均只在表单中保存省份、城市，**不保存经纬度或精确地址**。

- 点击定位后才调用浏览器 Geolocation API。HTTPS / localhost 环境需用户允许定位。
- 当前位置仅用于调用 [BigDataCloud 浏览器城市解析接口](https://www.bigdatacloud.com/free-api/free-reverse-geocode-to-city-api)，不使用 IP 定位推断，不发送报名答案或账号信息。该服务无需 API key；失败或城市无法匹配时回退为手动选择。正式上线可按业务需要替换为自己的城市解析接口。
- 拒绝定位、超时、网络不可达或不支持定位均可手动选择；不强制授权。手动修改会取消待完成的定位，避免晚到的结果覆盖用户选择。
- 手动省市数据本地打包，来自 [Administrative-divisions-of-China](https://github.com/modood/Administrative-divisions-of-China)，许可证保存在 `src/data/LICENSE`。直辖市统一保存到市级；港澳及台湾、其他地区另作入口，不表示产品适用范围。
- 定位结果处理和省市校验有单元测试；浏览器中验证了手动选择路径，真实设备定位效果依赖浏览器授权和服务可用性。

## 数据兼容

沿用存储键 `wujiang.signup.v1`。新版提交使用 `schemaVersion: 4`。前 3 版有效报名继续显示等待，修改时迁移含义明确的答案；多个设备不会被擅自选成一台，流量区间不会被擅自换成一个精确数值。保留历史答案供编辑参考，新提交必须满足 12 题校验。

- `src/App.vue`：登录、提交状态和简介弹窗
- `src/components/RegistrationFields.vue`：题目和条件追问
- `src/components/LocationCard.vue` / `src/location.js`：城市定位、选择和解析
- `src/model.js`：新版校验、迁移和存储
- `src/previous-model-v3.js` / `src/legacy-model.js`：历史数据读取兼容
- `tests/`：必填、分支、互斥、定位数据、迁移和存储容错测试

## 后续接入

当前为前端展示版，有赞登录、Ultra 订单、灯牌等级为模拟数据，报名仅保存在当前浏览器，不分配名额、不生成订单、不付款。

`App.vue` 的 `signIn()` 和 `submit()` 分别是登录与报名接口接入位置；正式接入后由服务端核验身份、订单、灯牌、领取数量和报名状态。前端展示不能作为领取凭证。具体资费、共享范围、设备适配规则由正式后台提供。

介绍图为用户提供的黑金卡面 `public/images/wujiang-card-reference.png`。CSS 仅展示卡面区域，旧海报下方的“待上线”和适用设备文字不作为当前产品规则。
