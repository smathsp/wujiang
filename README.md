# 无疆卡报名

手机端优先的前端展示页，原生 HTML / CSS / JavaScript，无运行依赖。

## 页面流程

1. 首次打开，弹出无疆卡介绍。
2. 确认介绍后，显示有赞登录入口。
3. 未填表用户登录后直接填写：4 道选择题、1 道选填场景描述。
4. 已提交用户显示“已收到，请等待”，可查看和修改报名信息。
5. 退出后重新登录、刷新页面，均能恢复已提交状态；修改未保存时可取消。

领取规则：卡片免费，下单支付 9.9 元邮费，流量费用另计。首批预计 2,000 张；所有人可报名，Ultra 用户、灯牌等级优先参考。

## 本地预览

需要 Node.js 18 或以上。

```sh
npm run dev
```

打开 http://127.0.0.1:4173 。可通过 `PORT=4180 npm run dev` 更改端口。

## 静态部署

```sh
npm run build
```

部署 `dist/`。也可直接托管根目录的 `index.html`、`styles.css`、`app.js` 和 `favicon.svg`。

## 演示与后续接入

- 当前登录按钮模拟有赞登录，不读取真实账号。订单、灯牌均标注为演示身份。
- 草稿、已提交信息与介绍弹窗状态保存在当前浏览器的 `localStorage`（键 `wujiang.signup.v1`）。没有网络提交、资格分配、订单或付款。
- `renderLogin()` 的 `#sign-in` 点击事件为有赞登录接入位置。
- `renderForm()` 内的提交处理需要替换为真实报名接口；`renderReceived()` 是已报名状态页面。
- 正式接入后由服务端核验登录、Ultra 订单、灯牌等级和报名状态；前端演示值不能作为真实领取凭证。
- 匿名直播及短视频场景授权为独立选填，默认不勾选。当前没有公开展示、上传或分享功能。
- 正式上线前补充具体资费、共享范围和设备适配规则。
