# 无疆卡报名

Vue 3 + Vite 的手机端报名展示页，使用 Composition API 和单文件组件。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

本地地址：http://127.0.0.1:4173 。

```sh
npm test
npm run build
npm run preview
```

部署时执行 `npm ci && npm run build`，静态目录使用 `dist/`。Vite 已配置相对资源路径，可以部署到子目录。开发预览和构建预览使用同一端口，请先停止另一进程。

## 页面与交互

- 首次介绍弹窗 → 有赞演示登录 → 5 道核心问题：使用设备、主要场景、实际月用量、网络困扰、无疆卡能解决的具体问题。
- 设备、用量使用底部选择面板，点选即回填；支持遮罩、关闭按钮、Esc 和浏览器返回关闭。
- Vue 响应式绑定保留输入焦点；错误显示在对应字段旁，提交时定位到首个错误。
- 主要场景和网络困扰各选一项；选择“其他”后才展开补充输入。设备按型号选择，需要时填写具体型号。
- 最后一题为 150 字内简答；手机底部固定提交按钮，照顾安全区和软键盘。
- 已报名显示“已收到，请等待”，可修改、取消修改；刷新和重新登录保留提交结果。
- 草稿和旧版原生页面共用 `wujiang.signup.v1` 存储键，已有演示数据会继续保留；旧提交仍显示等待结果，修改时补充新问题。不会自动编造新问题的答案。

## 文件

- `src/App.vue`：登录、表单、提交状态和弹窗流程
- `src/components/BottomSheet.vue`：底部弹窗、焦点管理与滚动锁定
- `src/components/ChoiceGroup.vue`：单选和多选
- `src/components/PickerField.vue`：设备和用量选择入口
- `src/model.js`：数据校验、历史数据兼容和本地存储
- `tests/signup.test.js`：兼容、校验及修改隔离等关键行为测试

## 后续接入

当前是前端演示：登录、Ultra 订单、灯牌信息是模拟数据，报名信息仅保存到当前浏览器，不分配资格、不生成订单、不付款。

`App.vue` 的 `signIn()` 是有赞登录接入位置，`submit()` 是报名接口接入位置。正式接入后由服务端核验身份、订单、灯牌和报名状态。展示数据不能作为领取凭证。

卡片免费领取，下单支付 9.9 元邮费，流量费用另计。首批预计 2,000 张；所有人可报名，Ultra 用户、灯牌等级优先参考。上线前需补充具体资费、共享范围和设备适配规则。

匿名场景展示授权独立选填，默认不勾选。当前没有公开展示、上传或分享功能。

框架参考：[Vue 快速开始](https://vuejs.org/guide/quick-start.html)、[表单输入绑定](https://vuejs.org/guide/essentials/forms.html)。
